termcal

A simple interactive monthly calendar for the Linux terminal, written in Python.

Features

Display a monthly calendar.

Highlight the current day.

Navigate between months using the left and right arrow keys.

Navigate between years using the up and down arrow keys.

Lightweight implementation using Python's standard library.

Requirements

Python 3

Linux terminal with curses support.

Installation

Clone the repository:

git clone https://github.com/USERNAME/termcal.git
cd termcal

Usage

Run the application:

python3 termcal.py
